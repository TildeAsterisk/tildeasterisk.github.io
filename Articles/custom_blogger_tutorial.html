How to fully customise your Blogger website. [HTML + CSS]

This document will teach you how to customise your Blogger website theme, starting from a chosen template. It is difficult to create a Blogger site from scratch because there is a lot of code required to allow the Blogger website to update itself with posts that you publish and other Blogger functionalities. As there is no blank Blogger template, we will start with a default Blogger theme that is most similar to the one we want to create.

Styling your Blogger website:

Open your Blogger page in the browser of your choice and open the Developer Tools (usually F12).

Here you can select an element to view and edit its CSS in real time. Once you have made a change you can right click and copy the CSS rule, including the name or class of the element, directly into the HTML code of your page on Blogger.

Upload & publish your changes:

In the sidebar, select the Theme page and choose a theme from the options given. Pick one that is most similar to the way you want your website to look; this will give you an easier starting point.
